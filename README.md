# 🌊 小鱼的心动海域

一个专为"小鱼"设计的可爱风格海底冒险游戏，和GZJ小狗一起收集星光吧！💕

## ✨ 特色

- 🐟 可爱的粉色小鱼（女生）
- 🐕 GZJ小狗向导全程陪伴
- 🎵 背景音乐《这条小鱼在乎》
- ⭐ 5个关卡 + 5个技能 + 5种道具
- 📱 支持iPhone（PWA可安装）
- 🎮 触摸操作优化

## 🚀 快速开始

### 电脑上玩

```bash
双击"启动游戏-iPhone版.bat"
```

### iPhone上玩

1. 电脑运行启动脚本
2. iPhone Safari输入显示的IP地址
3. 点击"分享"→"添加到主屏幕"
4. 完成！

详细说明：[安装和使用指南.md](./安装和使用指南.md)

## 📋 最后一步

生成游戏图标：
1. 打开 `生成图标.html`
2. 下载生成的图标文件
3. 放到 `dist/` 目录

## 🎮 游戏玩法

- **移动**：键盘方向键 / 手指滑动
- **冲刺**：空格键 / 冲刺按钮
- **目标**：收集星光，躲避水母
- **升级**：解锁新技能和道具

## 📁 项目结构

```
dist/               # 游戏文件（可直接部署）
├── index.html     # 主页面
├── app.mjs        # 游戏逻辑
├── engine.mjs     # 游戏引擎
├── background.mp3 # 背景音乐
├── manifest.json  # PWA配置
└── service-worker.js  # 离线支持
```
